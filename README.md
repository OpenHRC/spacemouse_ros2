# spacemouse_ros2

This is ROS2 spacemouse node based on [PySpaceMouse](https://github.com/JakubAndrysek/PySpaceMouse).

spacemouse_ros2 is forked from [spacemouse_publihser](https://github.com/frankarobotics/franka_spacemouse/tree/main/src/spacemouse_publisher) in [franka_spacemouse](https://github.com/frankarobotics/franka_spacemouse) repository by Franka Robotics, and aims to be for general usage as spacenav_node.

*This node will only work with PySpaceMouse V1.1.5.
```bash
$ pip install pyspacemouse==1.1.5
```
Newer versions of PySpaceMouse are currently unsupported.~~~~
