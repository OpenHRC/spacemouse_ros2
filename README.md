# spacemouse_ros2

This is ROS2 spacemouse node based on [PySpaceMouse](https://github.com/JakubAndrysek/PySpaceMouse), included in this repository as git submodule.

spacemouse_ros2 is forked from [spacemouse_publihser](https://github.com/frankarobotics/franka_spacemouse/tree/main/src/spacemouse_publisher) in [franka_spacemouse](https://github.com/frankarobotics/franka_spacemouse) repository by Franka Robotics, and aims to be for general usage as spacenav_node.

*This node will works with PySpaceMouse newer than v2.0.0.

The dependency is automatically solved via rosdep.

Legacy versions of PySpaceMouse supported on [legacy branch](https://github.com/OpenHRC/spacemouse_ros2/tree/legacy).
